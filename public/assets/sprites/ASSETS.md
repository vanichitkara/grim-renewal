# Sprite assets

All art in this folder is original, generated by scripts/make-sprites.ts.
It is free to use (CC0-style). Regenerate with `npx tsx scripts/make-sprites.ts`.

Every file is a horizontal strip: frame i starts at x = i * frame width.
Colours come from the animation.md palette plus the dark tones already used in the code.
